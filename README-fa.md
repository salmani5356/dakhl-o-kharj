# دخل و خرج (Dakhl o Kharj) — راهنمای ساخت APK و انتشار

اپ کاملاً آفلاین است (داده‌ها فقط روی گوشی). پوشهٔ `docs/` خودِ اپ است و همان را GitHub Pages هم نمایش می‌دهد (نسخهٔ PWA).

## ۱) گذاشتن روی گیت‌هاب
1. یک ریپوی جدید بسازید و کل محتویات این پوشه را آپلود کنید.
2. Settings ← Pages ← Source: `main` و پوشهٔ `/docs` (نسخهٔ وب/PWA).

## ۲) ساخت کلید امضا (فقط یک‌بار)
1. Actions ← **Create signing key** ← Run workflow ← یک رمز بنویسید.
2. در پایان اجرا، artifact با نام `keystore` را دانلود کنید (`release.jks` و `keystore.b64`).
3. **`release.jks` و رمز را جای امن چند‌نسخه‌ای نگه دارید.** اگر گم شود دیگر نمی‌توانید اپ را آپدیت کنید.
4. Settings ← Secrets and variables ← Actions، این‌ها را بسازید:
   - `KEYSTORE_B64` = محتوای `keystore.b64`
   - `KEYSTORE_PASSWORD` = رمز
   - `KEY_PASSWORD` = همان رمز
   - `KEY_ALIAS` = `spendbook`

## ۳) ساخت APK
Actions ← **Build Android** ← Run workflow. بعد از چند دقیقه artifact `spendbook-android` شامل APK (debug و release) و AAB آماده است. هر اجرا شمارهٔ نسخه را خودکار بالا می‌برد.
فایل `app-release.apk` (امضاشده) را برای مایکت و AAB را برای گوگل‌پلی بدهید.

## ۴) قبل از اولین انتشار
- **شناسهٔ بسته:** پیش‌فرض `ir.kharjnegar.app` است. بعد از انتشار قابل تغییر نیست. اگر می‌خواهید عوض کنید، فقط `appId` در `capacitor.config.json` را عوض کنید.
- **دکمهٔ خرید پریمیوم:** در نسخهٔ اندروید عمداً مخفی است (`SHOW_PREMIUM`)، چون پرداخت داخل اپ باید با سیستم پرداخت خودِ استور (مثلاً مایکت) وصل شود. قوانین هر استور را خودتان بررسی کنید.
- **سیاست حریم خصوصی:** فایل `docs/privacy.html` است؛ بعد از فعال شدن Pages آدرسش `https://USER.github.io/REPO/privacy.html` می‌شود و در فرم استورها وارد کنید.
- متن معرفی در `STORE-LISTING.md` آماده است.

## سررسید و آلارم (اجاره، قسط، شارژ…)
در تنظیمات ← «سررسیدها» هر پرداخت ماهانه را با روز ماه (مثلاً اول هر ماه)، ساعت و «چند روز قبل» تعریف کنید. در اندروید، اعلان محلی حتی وقتی اپ بسته است می‌آید و بعد از ریستارت گوشی هم باقی می‌ماند. اولین بار اجازهٔ اعلان خواسته می‌شود؛ برای دقیق بودن ساعت، در تنظیمات گوشی «آلارم‌ها و یادآورها» را برای اپ روشن کنید. در نسخهٔ وب/PWA فقط وقتی اپ باز است سررسیدها نشان داده می‌شوند.

## نکته‌های صادقانه
- این بستهٔ اندروید در محیط من روی دستگاه واقعی اجرا نشده؛ ساخت و تست روی گوشی با اولین اجرای Actions انجام می‌شود. اگر خطایی داد، لاگ را برایم بفرستید.
- گوگل‌پلی برای توسعه‌دهندهٔ ایرانی دشوار است (پرداخت و تأیید حساب)؛ مایکت و بازارهای مشابه ساده‌ترند.
- بک‌آپ JSON اپ (تب تنظیمات) برای جابه‌جایی گوشی لازم است؛ داده‌ها فقط روی همان گوشی‌اند.
